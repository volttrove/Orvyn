PixelOS - INMP441 fallback visualizer
====================================

Behavior:
- When A2DP is connected, visualization uses the Bluetooth PCM stream.
- When A2DP is disconnected, the INMP441 microphone is enabled and drives the same visualizers.
- The microphone I2S driver is stopped again when A2DP reconnects.

INMP441 wiring for the project's ESP32-WROOM-32:
- VDD -> 3V3
- GND -> GND
- SCK / BCLK -> GPIO 18
- WS / LRCL -> GPIO 5
- SD / DOUT -> GPIO 4
- L/R -> GND (left channel)

GPIO 6 is intentionally avoided because ESP32-WROOM-32 uses GPIO 6-11 for internal flash.

The microphone uses I2S_NUM_1 so it does not intentionally share the A2DP/PCM5102A I2S port.
Built for the project's Arduino-ESP32 2.0.x setup. Hardware testing is still required.

Channel L/R (v2):
Firmware mencoba channel RIGHT dulu. Jika INMP441 hanya mengeluarkan data nol selama
~1,5 detik (channel tidak cocok dengan pin L/R), firmware otomatis berpindah ke LEFT
(maksimal 2 percobaan). Lihat Serial Monitor: "INMP441: data nol terus, mencoba channel lain".
